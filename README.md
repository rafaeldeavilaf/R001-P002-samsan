# SAMSAN

Juego educativo web y estático para niños de 6 a 12 años: un mundo de biomas, uno por materia, donde cada tema del colegio se vuelve una zona nueva.

- Sitio: https://rafaeldeavilaf.github.io/R001-P002-samsan/
- Estado, decisiones y plan por etapas: [`docs/decisiones-vigentes.md`](docs/decisiones-vigentes.md). Es la fuente única de verdad.
- Cómo trabajar en el repo, comandos y reglas: [`CLAUDE.md`](CLAUDE.md).
- Notas legales del sitio: `legal.html`, generado por `tools/build.py`. Licencias de terceros: [`docs/licencias.md`](docs/licencias.md).

Publicar es hacer push a `main`: GitHub Actions regenera, construye, prueba y publica solo si todo pasa.
